# WhatsApp Payment Reminder Automation

Automated WhatsApp Payment Reminder System built with n8n, Evolution API, Docker & PostgreSQL.

## What it does
- Sends automatic payment reminders on WhatsApp on day before due date
- Tracks paid / unpaid status in PostgreSQL
- Stops reminders automatically after payment
- Runs 24/7 on cloud using Docker

## Tech Stack
- n8n (Workflow Automation)
- Evolution API (WhatsApp)
- Docker + Docker Compose
- PostgreSQL
- Node.js

## Business Impact
- Reduced manual follow-up by 80%
- Improved payment collection speed
- Zero manual calls for reminders
